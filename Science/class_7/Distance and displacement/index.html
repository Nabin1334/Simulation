Understanding Through Examples

Distance Examples

Car Odometer: Shows total distance traveled regardless of direction.

Running Track: Each lap adds to distance even if you return to start.

Hiking Trail: Winding trail length is the distance.

Displacement Examples

GPS Navigation: Shows straight-line distance to destination.

Airplane Route: Direct "as the crow flies" distance matters most.

Position Change: Net movement from starting point.

Key Insight

Distance and displacement are equal only when the path is a straight line.

In circular motion, displacement can be zero while distance keeps increasing.

Displacement has direction (vector), distance doesn't (scalar).
