Speed (Scalar)

Speed is a scalar quantity that measures how fast an object is moving.

Speed = Distance ÷ Time
📏 "The car is moving at 8 meters per second"
Velocity (Vector)

Velocity is a vector quantity that measures how fast AND in which direction an object is moving.

Velocity = Displacement ÷ Time
🧭 "The car is moving at 8 m/s EAST"
Key Differences
Property Speed Velocity
Type Scalar Vector
Has Direction? ❌ No ✅ Yes
Formula Distance / Time Displacement / Time
